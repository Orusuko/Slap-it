# @slay-it/server

Servidor Express + Socket.IO con la máquina de estados de partida.

**Estado:** snapshot previo a P5 (sin setlist cloud, karaoke por turnos,
Adivina la canción, sync de playhead ni biblioteca Supabase).

**No se usa** en el despliegue de GitHub Pages: la app publicada corre la
partida en el navegador del anfitrión y usa Supabase Realtime.

**No lo uses** como referencia de paridad de producción del karaoke actual.
Para jugar en fiesta, usa `apps/web` con Supabase configurado.
